Patient User Stories

ID	User Story
US-P-001	As a patient, I want to register so that I can use the appointment system.
US-P-002	As a patient, I want to login so that I can access my account.
US-P-003	As a patient, I want to view doctors so that I can choose a doctor.
US-P-004	As a patient, I want to view a doctor's profile so that I can understand their specialization and experience.
US-P-005	As a patient, I want to view available slots so that I can choose an appointment time.
US-P-006	As a patient, I want to book an appointment so that I can consult a doctor.

US-P-008	As a patient, I want to reschedule an appointment so that I can change my appointment time.
US-P-009	As a patient, I want to cancel an appointment so that I can release a booking I no longer need.
